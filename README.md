# 中国象棋（网页多人实时对弈）

在浏览器里和下中国象棋。创建房间后，把**邀请链接、房间号或二维码**发给微信好友，对方点开即可加入。红黑双方的走棋通过 WebSocket 实时同步，不是本地单机文件。

创建房间的一方执红，加入的一方执黑（棋盘会对黑方翻转）。同一链接还可以用来重连并恢复当前局面。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
cd xiangqi
npm install
npm test          # 先跑规则单元测试
npm start         # 启动服务
```

浏览器打开 [http://localhost:8080](http://localhost:8080)。

在同一台电脑上验证多人：再开一个窗口（或一个普通窗口加一个无痕窗口），一方点「创建对局」，另一方输入房间号加入（也可以把邀请链接粘贴到第二个窗口）。随后即可下完整一盘：走棋、将军、认输、求和、再来一局。

默认监听 `8080` 端口，可用环境变量修改：

```bash
PORT=3000 npm start
```

## 邀请好友一起下

1. 点「创建对局」，你会得到 **6 位房间号**、邀请链接和二维码。
2. 用「复制链接」「复制房间号」或「发给微信好友」（支持系统分享时）发给对方。
3. 好友打开链接，或在首页输入房间号，即可加入并开始对弈。
4. 对局中途刷新或短暂掉线，用**同一条链接**在同一浏览器中打开，会按本地保存的身份重连并恢复棋局。

### 用手机邀请微信好友

两部不在同一网络的手机要对弈，需要把本服务部署到一个 **HTTPS 公网地址**（见下方部署）。本地 `http://localhost` 或局域网 IP 通常无法直接从微信里打开，或只能给连着同一 Wi-Fi 的人用。

若只是同一局域网试用，可用电脑的局域网 IP，例如 `http://192.168.1.8:8080`，双方手机连同一 Wi-Fi 后打开该地址。微信内置浏览器对 HTTP 页面限制较多，仍建议优先用 HTTPS。

### 在微信中打开

本游戏按微信 H5 做了适配：不用悬停操作、避免页面上下弹跳、使用 WebSocket 而不是 WebRTC，并设置了标题、简介、viewport 和分享卡片（og）信息。

**如果微信里打不开、白屏或无法走棋：** 点击右上角「···」，选择 **「在浏览器中打开」**，用系统浏览器访问同一链接。部分微信版本会拦截未备案域名、非 HTTPS 页面或本地地址，这是微信本身的限制，不是必须付费的实时通信密钥。

## 部署

同一个 HTTPS 服务同时提供网页和 WebSocket（同源 `/ws`），**不需要**第三方实时通信的付费 Key。请把反代的 WebSocket 升级打开，并转发 `Host`、`X-Forwarded-Proto`、`X-Forwarded-Host`，以便邀请链接和分享图片使用正确的公网地址。

### Docker

```bash
docker build -t xiangqi .
docker run --rm -p 8080:8080 xiangqi
```

前面加 Nginx、Caddy 或云厂商负载均衡做 HTTPS 即可。例如 Caddy：

```
chess.example.com {
    reverse_proxy localhost:8080
}
```

环境变量：

- `PORT`：监听端口，镜像默认 `8080`
- `HOST`：监听地址，默认 `0.0.0.0`

健康检查：`GET /health`

房间在双方都离开约 **1 小时** 后回收。服务重启后内存中的房间会丢失，玩家需要重新创建。

## 对局功能

- 走棋：先点己方棋子，再点目标位置，合法落点会高亮
- 显示轮到哪一方，被将军时会提示
- 将死、困毙结束对局
- 认输；求和必须对方同意
- 终局后可发起「再来一局」（双方同意后交换红黑）
- 无 AI，目前仅支持两人一桌

## 规则说明（含简化长将）

走法与常规中国象棋一致：

- **帅/将**：九宫内一次走一格直线；两将不能在同一路上隔空对脸（飞将）。
- **仕/士**：九宫内一次走一格斜线。
- **相/象**：走田字，不能过河；田心有子则塞象眼，不能走。
- **马**：走日字；近处直行一格有子则蹩马腿。
- **车**：直线行走，不能跳子。
- **炮**：不吃子时与车相同；吃子必须恰好隔一个炮架。
- **兵/卒**：未过河只能向前；过河后可向前或横走，不能后退。
- 走子后若己方将/帅仍被将军，该着非法。
- 对方无合法着法：已被将军则为将死，否则为困毙，均判负。

**长将简化规则：** 同一将军局面重复出现三次时，禁止再走该着；若因此没有其他可走之着，则判长将违规负。这是为了便于联网对弈的简化约定，与正式竞赛中的长将、长捉细则并不完全等同。对局里的「规则」按钮也可查看这段说明。

规则由服务端权威校验，客户端的非法着法会被拒绝。
